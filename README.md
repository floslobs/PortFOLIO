## 👩‍💻 Sobre este proyecto

Este repositorio contiene el código y los recursos multimedia de mi **portfolio web**, pensado como un espacio centralizado para presentar mi perfil, mi recorrido académico/profesional y los proyectos en los que vengo trabajando.

Es el lugar donde reúno la presentación visual, el acceso a mi currículum y demostraciones en imagen y video de distintos desarrollos.

El proyecto está construido con tecnologías web fundamentales (**HTML**, **CSS** y **JavaScript**), combinando estructura, estilos personalizados, interactividad y recursos multimedia locales (`img/` y `vid/`).

---

## 🚀 Estructura y secciones del portfolio

### 01. Estructura principal y presentación

**`index.html` | `styles.css` | `script.js`**

La base del sitio web organiza el contenido, la estética visual y el comportamiento interactivo.

- Maquetado de secciones en `index.html`.
- Diseño visual, colores, tipografías y disposición en `styles.css` (junto con `fondo.jpg` y `perfil.jpeg`).
- Interactividad y comportamiento dinámico en `script.js`.

### 02. Proyectos y demostraciones multimedia

**`img/` | `vid/`**

El portfolio incorpora capturas y videos demostrativos para mostrar el funcionamiento de los proyectos de forma visual.

- **Portfolio:** `portfolio.jpeg` y `portfolio.mp4`.
- **Proyecto Emergencia:** `Projectemergencia.jpeg` y `projectemergencia.mp4`.
- **Registro:** `registro.jpeg` y `registro.mp4`.
- **Ubicación y recursos gráficos:** `ubicacion.jpg` y `fondo.jpg`.

### 03. Perfil y currículum

**`Curriculum_FlorenciaLobosco.pdf` | `perfil.jpeg`**

Incluye el documento de CV en PDF y la imagen de perfil para complementar la presentación profesional.

## ▶️ Cómo visualizar el portfolio

Al tratarse de un sitio web estático con recursos locales, podés abrirlo directamente en tu navegador o servirlo con un servidor local:

1. Abrir `index.html` en cualquier navegador web (Chrome, Firefox, Edge, etc.).
2. O bien, si usás VS Code, abrir la carpeta con la extensión **Live Server** para previsualizar los cambios en tiempo real.
